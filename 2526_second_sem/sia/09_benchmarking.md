# Benchmarking
Testing, evaluation, and benchmarking

---

## Testing, Evaluation, and Benchmarking

Assuming you've either created a component in house or outsourced it, evaluating if that component actually functions as intended is still a required step

The 3 terms here mean
- Testing - Ensuring base functionality
- Evaluation - Ensuring functional requirements are met
- Benchmarking - Ensuring non functional requirements are met

---

## Testing

Testing, in this context, ensures that the component built works as intended without bugs or errors

This is primarly done through automated tests and user run throughs

---

## Evaluation

Given your list of functional requirements, this is a test done to check if the component is able to deliver on all those requirements

This is also done through automated tests nad user run throughs but with a different focus

---

## Benchmarking

Given your list of non functional requirements, does the component meet them

Speed and performance, user retention, error rate, data, first load,
